📘 Istemal Guide (Hindi)

1. Preset Chunein

Left panel se koi bhi preset click karein — sound turant preview hoga aur uske parameters editor mein load ho jayenge.

2. Customize Karein

Frequency, duration, waveform, filter aur noise mix jaise sliders se sound ko apni zaroorat ke hisaab se badlein. Har change ke baad ▶ button dabakar preview sunein.

3. Reverb aur Bitcrush

Reverb Tail se echo effect add karein, ya 8-bit Bitcrush se retro game jaisa texture paayein.

4. Download Karein

"Download WAV" button se sound file save karein. Demo mode mein 3 free downloads milte hain (watermark ke saath), lifetime unlock ke baad unlimited clean downloads milte hain.

5. Batch Variations (Pro)

Ek click mein 5 randomized variations generate karein aur unhe ZIP file mein download karein — game dev aur content creators ke liye perfect.

6. Kis kaam aayega?

  • YouTube/Reels ke liye transition aur notification sounds
  • Mobile game development ke liye UI aur retro effects
  • Podcast intros ke liye whoosh aur impact sounds
  • App/website ke liye click aur success/error alerts
